# Generated Schemas

This directory is reserved for normalized schema docs generated by:

```bash
npm run ingest:schemas -- --source dir --input data/schemas
npm run ingest:schemas -- --source crd --input examples/my-crd.yaml
npm run ingest:schemas -- --source kubernetes --input openapi.json
npm run ingest:schemas -- --source cluster --input openapi.json
```

The application falls back to the fixture schemas in `data/schemas/*.json` when this directory has no generated JSON files.
